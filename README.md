# ScoreLive — онлайн-оценивание соревнований

В архиве находится **один рабочий файл `index.html`** и этот README.

## Функции
- Панель организатора, панель судьи и публичное табло.
- Три категории участников: детские, средние и выпускные классы.
- Отдельные критерии оценивания для каждой категории.
- Редактирование названий критериев и максимального балла каждого критерия.
- До 30 туров; выбор активного тура.
- Оценки судей сохраняются отдельно для каждого участника и каждого тура.
- Повторная оценка тем же судьёй заменяет его предыдущую оценку в этом туре.
- Табло показывает баллы судей, результаты по турам, сумму и рейтинг отдельно по категориям (детские → средние → выпускные).
- При равных баллах участники делят место; участники без оценок места не получают.
- Удаление участника удаляет и его оценки; удаление судьи отключает его ссылку, но оценки сохраняются.
- Выбор цвета сайта (6 готовых тем, включая светлую, и свой цвет акцента) в панели организатора; цвет применяется у всех устройств.
- Firebase Firestore обеспечивает синхронизацию между устройствами в реальном времени.

## Установка Firebase
1. Создайте проект на https://console.firebase.google.com/.
2. Добавьте Web App и скопируйте конфигурацию Firebase.
3. Создайте Firestore Database.
4. Откройте `index.html` и замените значения-заглушки в `firebaseConfig` на параметры своего проекта.
5. Настройте правила Firestore и авторизацию судей до официального использования.

**Важно о безопасности:** судейская ссылка содержит идентификатор судьи, но сама по себе не является надёжной авторизацией. Не оставляйте Firestore открытым на запись для всех пользователей. Для реального соревнования настройте Firebase Authentication и правила доступа.

## Публикация на GitHub Pages
1. Создайте репозиторий GitHub.
2. Загрузите в корень репозитория `index.html` (README можно загрузить дополнительно).
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch → `main` → `/ (root)` → Save.
5. Сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Ссылки внутри сайта
- Организатор: главная ссылка.
- Судья: создаётся в панели организатора кнопкой создания ссылки. По судейской ссылке вкладки организатора скрыты.
- Табло: кнопка копирования ссылки на табло.

## Подсчёт
- Балл одного судьи за участника в туре — сумма по критериям.
- Общая сумма — сумма оценок судей по всем турам.
- Средний общий и средний за тур — среднее арифметическое оценок, округлённое до десятых (5,36879… → 5,4).
- Если сумма равна, выше стоит участник с большим средним.
- Места рассчитываются отдельно внутри каждой категории.

## Демо
Если Firebase не настроен, сайт работает локально через хранилище браузера. Данные не синхронизируются с другими устройствами (только между вкладками этого браузера).
