# ScoreLive — онлайн-оценивание соревнований

Статический одностраничный сайт для GitHub Pages + Firebase Firestore (SDK 10.12.2).

## Возможности
- Панель организатора: участники, создание судейских ссылок, сводная таблица.
- Турнирная сетка: создание заданного количества туров (до 30), выбор активного тура организатором; история оценок сохраняется по каждому туру.
- Панель судьи: персональная ссылка, выбор участника, оценка 0–10 в активном туре, изменение своей оценки.
- Табло: рейтинг, оценка каждого судьи, средний балл и сумма.
- Обновление данных в реальном времени через Firestore.

## Настройка Firebase
1. Создайте проект на https://console.firebase.google.com/
2. Добавьте Web App в настройках проекта и скопируйте `firebaseConfig`.
3. Создайте Firestore Database (Production mode).
4. В `index.html` замените значения `YOUR_API_KEY`, `YOUR_PROJECT_ID` и остальные поля на данные вашего Firebase-проекта.
5. Для первого теста можно временно использовать `firestore.rules` из этого архива и опубликовать правила.

**Важно:** приложенные правила открывают чтение и запись всем посетителям. Это только быстрый демонстрационный вариант. Для официального соревнования настройте Firebase Authentication и строгие правила доступа, иначе посторонний человек сможет изменить оценки или удалить участников.

## Публикация на GitHub Pages
1. Создайте GitHub-репозиторий, например `scorelive`.
2. Загрузите `index.html` (и при желании `firestore.rules`, `README.md`).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch → `main` → `/root` → Save.
5. Через минуту сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/scorelive/`.

## Ссылки

- Табло: `https://ВАШ-САЙТ/#board`
- Судья: ссылка автоматически создаётся в панели организатора после добавления судьи.

## Подсчёт
Средний балл за тур = сумма оценок в этом туре / количество выставивших судей.
Общая сумма участника = сумма всех оценок по всем турам.
Итоговый рейтинг сортируется по общей сумме баллов; табло показывает отдельные оценки судей и сумму для каждого тура.
Судья, созданный организатором, идентифицируется по персональному ID в ссылке. Повторная оценка тем же судьёй заменяет предыдущую для этого участника.

## Демо без Firebase
Без настройки Firebase сайт запускается в локальном демонстрационном режиме, но данные сохраняются только в браузере и не синхронизируются между устройствами.
