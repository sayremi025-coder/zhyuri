# ScoreLive — онлайн-оценивание соревнований

Статический одностраничный сайт для GitHub Pages + Firebase Firestore (Firebase Web SDK 10.12.2).

## Что умеет
- Панель организатора, рабочая панель судьи и публичное табло.
- Участники распределяются по трём категориям: **детские классы**, **средние классы**, **выпускные классы**.
- Для каждой категории — собственный набор критериев и собственные максимальные баллы.
- Максимальный балл каждого критерия редактируется организатором; итоговый максимум категории пересчитывается автоматически.
- Судья ставит оценку по каждому критерию отдельно. Система проверяет, что оценка находится в пределах 0…максимум.
- До 30 туров; оценки каждого судьи хранятся отдельно по каждому участнику и туру.
- Повторная отправка оценки тем же судьёй заменяет предыдущую оценку этого судьи в выбранном туре.
- Табло показывает оценки судей, сумму по туру, общий результат и рейтинг отдельно по каждой возрастной категории.
- Синхронизация между устройствами в реальном времени через Firestore.

## Стартовые критерии
Это примеры, их можно полностью менять в панели организатора.

| Категория | Стартовые критерии | Максимум |
|---|---|---:|
| Детские классы | Старание и участие; выполнение задания; творческий подход; дисциплина | 5 за каждый, всего 20 |
| Средние классы | Техника; качество; оригинальность; командная работа | 10 за каждый, всего 40 |
| Выпускные классы | Сложность; техника; презентация и артистизм; итоговый результат | 15, 15, 10, 10, всего 50 |

## Настройка Firebase
1. Создайте проект на https://console.firebase.google.com/.
2. Добавьте Web App в настройках проекта и скопируйте `firebaseConfig`.
3. Создайте Firestore Database.
4. В `index.html` замените значения `YOUR_API_KEY`, `YOUR_PROJECT_ID` и остальные поля на данные вашего Firebase-проекта.
5. Настройте правила Firestore. Не оставляйте публичную запись для реального соревнования.

**Безопасность:** текущая схема персональных ссылок идентифицирует судью по ID в URL, но не является полноценной аутентификацией. Для официального мероприятия включите Firebase Authentication и правила Firestore, разрешающие каждому судье менять только собственные оценки, а организатору — управлять соревнованием. Не публикуйте открытые правила `allow read, write: if true`.

## Публикация на GitHub Pages
1. Создайте репозиторий GitHub.
2. Загрузите `index.html`.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch → `main` → `/root` → Save.
5. Откройте адрес вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Ссылки
- Организатор: главная ссылка сайта.
- Судья: создаётся кнопкой «Создать ссылку» в панели организатора.
- Табло: кнопка «Копировать ссылку на табло».

## Подсчёт
- Балл судьи за участника в туре — сумма баллов по всем критериям.
- Сумма за тур — сумма оценок всех судей в этом туре.
- Общий результат — сумма оценок по всем турам и судьям.
- Места считаются отдельно внутри каждой категории.
- Средний балл на табло — среднее значение всех полученных оценок по турам.

## Демо-режим
Если Firebase не настроен, сайт сохраняет данные в localStorage текущего браузера. Этот режим подходит только для проверки интерфейса и не синхронизирует судей между устройствами.
